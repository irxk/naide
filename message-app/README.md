## Quick Start

```bash
npm install
npm run build
npm run dev
```

Before running, set a strong, private `JWT_SECRET` in your environment. For example, generate one with:

```bash
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"
```

Add the generated value to the ignored `.env` file as `JWT_SECRET=<generated-value>`, or provide it through the process environment. Never commit or bake the secret into the image.
