## API Endpoints

- `GET /api/health` — Health check
- `GET /api/messages?page=1&limit=20&search=` — List messages (paginated)
- `POST /api/messages` — Create message
- `GET /api/messages/:id` — Get message
- `PUT /api/messages/:id` — Update message
- `DELETE /api/messages/:id` — Delete message
- `DELETE /api/messages/:id/soft` — Soft delete message
- `PUT /api/messages/:id/restore` — Restore message
- `POST /api/messages/batch` — Batch create messages
- `DELETE /api/messages/batch` — Batch delete messages
- `POST /api/upload` — File upload
- `POST /api/webhooks` — Register webhook
- `GET /api/webhooks/health` — Webhook health
