Page Generation

The page keyword generates complete HTML files from a declarative element tree. Elements are automatically classified into <head> and <body>.

Basic Page

page "index.html":
  title "My App"
  h1 "Hello World"
  p "Welcome to my site"

This generates a full HTML5 document with proper <!DOCTYPE>, <meta charset>, and viewport tags.

Nested Elements

Use indentation to nest elements. The first argument becomes the CSS class:

page "app.html":
  title "Dashboard"
  style "styles.css"
  div "container":
    h1 "Dashboard"
    div "cards":
      div "card":
        h3 "Users"
        p "1,234"
      div "card":
        h3 "Revenue"
        p "$5,678"
  script "app.js"

Head vs Body Elements

Elements are automatically placed in the correct section:

Element Placement Output
title "text" <head> <title>text</title>
style "file.css" <head> <link rel="stylesheet" href="file.css">
meta "name" "content" <head> <meta name="name" content="content">
script "file.js" <body> <script src="file.js"></script>
img "src" "alt" <body> <img src="src" alt="alt">
a "url" "text" <body> <a href="url">text</a>
input "type" "name" <body> <input type="type" name="name">

Any other tag (h1, h2, p, div, span, form, etc.) goes to <body>.
