Syntax Reference

NAIDE uses indentation-based blocks, keyword-driven statements, and explicit type annotations. The first token on each line determines intent.

Variables

Variables are immutable by default (const). Use mut for mutable bindings (let).

str name = "hello"          # immutable (const)
int count = 42
num price = 9.99
bool active = true
list items = [1, 2, 3]
map config = {host: "localhost"}
any data = null

mut int counter = 0          # mutable (let)
mut str label = "init"

Type Inference (auto)

Use auto to let the compiler infer the type from the assigned value:

auto name = "hello"              # inferred as str
auto count = 42                  # inferred as int
auto price = 9.99                # inferred as num
auto active = true               # inferred as bool
auto items = [1, 2, 3]          # inferred as list
auto config = {host: "localhost"} # inferred as map

mut auto counter = 0             # mutable with inferred type

Compiles to const (or let with mut) without explicit type annotations in the output.

Destructuring

Extract values from objects and arrays with destructuring syntax:

Object Destructuring

auto {name, age} = user
auto {name, age, ...rest} = user   # with rest
str {first, last} = names           # typed destructuring

Array Destructuring

auto [a, b] = items
auto [first, ...rest] = items       # with rest
int [x, y, z] = coordinates         # typed destructuring

Spread Operator

Spread arrays and objects with ...:

list merged = [...a, ...b]                 # merge arrays
map combined = {...defaults, ...overrides}  # merge objects
map updated = {...user, name: "new"}        # override a field

String Interpolation

Double-quoted strings with {expr} are automatically interpolated into template literals:

str greeting = "Hello {name}, you have {count} items"

Compiles to:

const greeting = `Hello ${name}, you have ${count} items`;

Functions

Functions use fn, with optional typed parameters and return type:

fn add(int a, int b) -> int:
  ret a + b

fn greet(str name, str prefix = "Hello"):
  log "{prefix}, {name}!"

Rest Parameters

fn sum(...int nums) -> int:
  mut int total = 0
  each n in nums:
    total += n
  ret total

Async Functions

fn.async fetchUser(str id) -> map:
  any res = await fetch("/api/users/{id}")
  ret await res.json()

Control Flow

If / Elif / Else

if count > 10:
  log "many"
elif count > 5:
  log "some"
else:
  log "few"

Ternary Expression

str size = if count > 10 then "big" else "small"

Loops

each — Iterate Arrays

each item in items:
  log item

each — Iterate Object Keys/Values

each key, val in config:
  log "{key}: {val}"

for — Numeric Range

for i in 0..10:
  log i

while

while active:
  log "running"
  active = false

Syntax Sugar

unless

Inverted if — runs the block when the condition is false:

unless active:
  log "not active"

until

Inverted while — loops until the condition becomes true:

until done:
  process()
  done = check()

repeat

Loop a fixed number of times:

repeat 5:
  log "hello"

is / isnt

Readable aliases for === and !==:

if status is "ok":
  log "success"
if status isnt "error":
  log "not an error"

swap

Swap two variables in one statement:

swap a, b

One-Line Functions

fn double(int x) -> int: ret x * 2
fn greet(str name): log "Hi {name}"

print

Alias for log:

print "hello world"

enum

Define enumerations:

enum Color: RED, GREEN, BLUE
log Color.RED   # 0

Pattern Matching

match status:
  "ok": log "success"
  "error": log "failed"
  _: log "unknown"

Compiles to a switch statement. Use _ for the default case.

Error Handling

try:
  data = await fetchData(url)
fail e:
  log.error e.message
ensure:
  log "request completed"

fail is NAIDE's catch. ensure is NAIDE's finally — the block always runs whether the try succeeds or fails. Both fail and ensure are optional:

try:
  conn = await openConnection()
  ret await conn.query("SELECT 1")
ensure:
  conn.close()

Type Checking

if typeof data == "string":
  log "is string"

if err instanceof TypeError:
  log "type error"

typeof returns the type as a string. instanceof checks if a value is an instance of a class or constructor.

Classes (model / schema)

Use model or schema to define classes with typed properties:

model User:
  str name
  str email
  int age = 0

  fn greet() -> str:
    ret "Hi, I'm {self.name}"

self refers to the current instance (compiles to this).

Class Inheritance (extends)

Use extends with schema or model for class inheritance:

schema Animal:
  str name
  str sound

  fn speak() -> str:
    ret "{self.name} says {self.sound}"

schema Dog extends Animal:
  init(str name):
    self.name = name
    self.sound = "woof"

  fn fetch(str item) -> str:
    ret "{self.name} fetches {item}"

The init keyword defines a constructor. Child classes inherit all properties and methods from the parent.

Admin Example

model Admin extends User:
  str role = "admin"
  fn permissions() -> list:
    ret ["read", "write", "delete"]

Pipe Operator (|>)

Chain operations for readable data transformations:

list result = data
  |> filter((x) => x.active)
  |> map((x) => x.name)
  |> sort()
list result = items
  |> filter((x) => x > 0)
  |> map((x) => x * 2)
  |> unique()
  |> sort()

Optional Chaining (?.)

Safely access nested properties without null checks:

str name = user?.profile?.name
str city = user?.address?.city
any result = obj?.method?.()

Returns undefined if any part of the chain is null or undefined.

Null Coalescing (??)

Provide a default value when the left-hand side is null or undefined:

str name = user?.name ?? "Anonymous"
int port = config?.port ?? 3000
str display = label ?? title ?? "Untitled"

Unlike ||, the ?? operator only falls through on null/undefined, not on 0, "", or false.

Imports & Exports

Imports

use express
use {readFile, writeFile} from "fs/promises"
use axios from "axios"

use compiles to import. When importing between NAIDE files, extensions are automatically rewritten to .mjs:

use {handleUser} from "./routes.naide"

Exports

pub fn helper() -> str:
  ret "exported"

pub str VERSION = "1.0.0"

pub marks functions and variables as exported (export).

Environment Variables

env:
  PORT       int default(3000)
  JWT_SECRET str required
  DB_URL     str default("data/")

Variables become constants read from process.env. Missing required variables cause the process to exit with an error.

HTTP Client

fn.async getUsers() -> any:
  any users = await api.get("https://api.example.com/users")
  ret users

fn.async createUser(map data) -> any:
  any result = await api.post("https://api.example.com/users", data)
  ret result

Available methods: api.get(url), api.post(url, body), api.put(url, body), api.del(url), api.raw(url, opts).

Plugin System

registerPlugin("logger", (opts) =>
  ret {log: (msg) => log "[{opts.prefix}] {msg}"}
)

any logger = usePlugin("logger", {prefix: "APP"})
logger.log("started")

list names = listPlugins()

registerPlugin(name, setup) registers a plugin factory. usePlugin(name, opts?) initializes on first call and returns cached exports. listPlugins() returns registered plugin names.
