NAIDE

One readable language, built to ship

$ npm install -g naider

Node.js, Python, Bun, TypeScript, Go, Java, Rust, C++, C, C#, Kotlin, Swift, Dart, PHP, Ruby

15 Code Generation Targets

Generate code for Node.js, Python, Bun, TypeScript, Go, Java, Rust, C++, C, C#, Kotlin, Swift, Dart, PHP, and Ruby. Hosted CI compiles and runs a representative program for all 15 targets; feature and framework coverage still varies by target.

AI-Native

Convenient ai.ask, ai.json, ai.stream, embeddings, RAG, and prompt-template syntax. Provider access still needs network connectivity and credentials.

Practical Built-in Toolkit

Readable control flow, optional type annotations, server and data-model syntax, editor support, diagnostics, and code generation in one language.

App-Building Syntax

NAIDE syntax covers servers, bots (Discord/Slack/Telegram/LINE), CLI apps, pages, email, GraphQL, desktop, mobile, and cron. Generated runtime support and dependencies vary by target.

One Consistent Syntax

One readable syntax for people and AI alike. Write less boilerplate without learning a second symbolic language.

Useful by Default

NAIDE uses one consistent syntax in source files, examples, editor tools, and generated projects.

MCP Server

Built-in naide-mcp stdio server using the stateless MCP 2026-07-28 protocol, with per-request metadata and server discovery.

Modern Syntax Sugar

Pipe operator (|>), optional chaining (?.), null coalescing (??), spread, auto type inference, destructuring, and more.

A Full API in 15 Lines

app.naideschema User:
  id    auto
  name  str required
  email str required email

db "data/"

server app port 3000:
  cors "*"
  crud "/api/users" User
  auth JWT_SECRET:
    protect "/api/*"
    public "/api/auth/*"

  post "/api/ask" (req, res):
    str answer = await ai.ask(req.body.prompt)
    ret {answer}
