NAIDE

AI-optimized language that transpiles to 15 targets

$ npm install -g naider

Node.js, Python, Bun, TypeScript, Go, Java, Rust, C++, C, C#, Kotlin, Swift, Dart, PHP, Ruby

15 Compilation Targets

Write once, transpile to Node.js, Python, Bun, TypeScript, Go, Java, Rust, C++, C, C#, Kotlin, Swift, Dart, PHP, and Ruby.

AI-Native

Built-in ai.ask, ai.json, ai.stream, embeddings, RAG, and prompt templates. Zero-dependency LLM integration.

55+ Built-in Features

Servers, bots, 40+ built-in functions, type inference, destructuring, pipes, optional chaining, spread, class inheritance — batteries included.

Full-Stack Built-in

Servers, bots (Discord/Slack/Telegram/LINE), CLI apps, HTML pages, email, GraphQL, desktop, mobile, cron — all built into the language.

Minimal Tokens

NAIDE uses ~40% fewer tokens than JavaScript. NAIDE-X uses ~80% fewer. Faster AI generation, more room in context windows.

Two Syntax Modes

.naide is human-readable. .nx is AI-optimized. Convert freely between them with naide convert.

MCP Server

Built-in naide-mcp binary for Claude Code integration. Let AI agents read, write, and run NAIDE code directly.

Modern Syntax Sugar

Pipe operator (|>), optional chaining (?.), null coalescing (??), spread, auto type inference, destructuring, and more.

A Full API in 15 Lines

app.naideschema User:
  id    auto
  name  str required
  email str required email

db "data/"

server app port 3000:
  cors "*"
  crud "/api/users" User
  auth JWT_SECRET:
    protect "/api/*"
    public "/api/auth/*"

  post "/api/ask" (req, res):
    str answer = await ai.ask(req.body.prompt)
    ret {answer}
