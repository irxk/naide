NaideVM

NaideVM is NAIDE's direct AST interpreter. It executes NAIDE source on Node.js without generating JavaScript. The public class is NaideVM; NativeEngine remains as a backwards-compatible alias.

Experimental direct native tier

An opt-in Windows x64 tier compiles a conservative scalar-numeric function subset to machine code. Build the Node-API bridge from a source checkout with Visual Studio C++ Build Tools installed:

npm install
npm run build:native-jit

Enable direct compilation with new NaideVM({ nativeMachineCode: true }). To compile only after repeated calls, set nativeMachineCodeThreshold to a positive call count; this tier currently considers functions containing range loops and keeps low-benefit leaf helpers on the existing fast tier. The backend uses liveness-based allocation across volatile XMM registers with stack spills, and can inline bounded immutable pure numeric helpers with simple conditional returns. Inlining preserves branch outcomes, source-line step charges, and call-depth checks. The native compiler also recognizes exact zero-initialized accumulator loops (triangular sums and unit increments), applies a closed-form reduction only within safe integer bounds, and still charges the original logical step budget. It supports integer remainder only for guarded range-iterator cases. Set nativeMachineCodeDiagnostics: true and read getNativeMachineCodeStats() for compile, inlining, code-size, native-call, warmup, and fallback counters. Unsupported functions and guarded arguments retain the existing NaideVM fast/interpreter fallback. Both modes are opt-in, Windows x64-only, and experimental.
